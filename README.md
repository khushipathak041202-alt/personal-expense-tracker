# Personal Expense Tracker (Python)

A beginner-friendly command-line project that lets a user:
- Add an expense with date, category, description, and amount
- View saved expenses
- See total spending and spending by category
- Save data locally in a CSV file

## Requirements
- Python 3.9 or later
- No third-party packages required

## Run
Open a terminal in this folder and run:

```bash
python expense_tracker.py
```

On some Windows setups, use `py expense_tracker.py`.
